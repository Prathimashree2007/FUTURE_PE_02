Created a UGC Ad Content Pack as part of my prompt engineering internship 🚀

For this project, I worked with a fitness product concept — FitFlex Adjustable Dumbbells — and used structured AI prompts to create short-form UGC advertising content.

The project focused on:

• Creating multiple hooks  
• Using the Problem → Solution → CTA framework  
• Writing conversational UGC scripts  
• Adapting content for Reels, Ads and YouTube Shorts  
• Creating CTAs and captions  
• Building a reusable prompt structure  

I also organized the prompts and generated outputs in a GitHub repository to keep the workflow documented and reusable.

This project helped me understand how the structure of a prompt can influence the tone, format and usefulness of AI-generated marketing content.
