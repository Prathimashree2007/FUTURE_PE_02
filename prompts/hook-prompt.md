# UGC Hook Generation Prompt

Generate 5 different hooks for FitFlex Adjustable Dumbbells.

Target audience:

- College students
- Working professionals
- Beginner fitness enthusiasts
- People working out at home

Main problem:

Traditional dumbbells and workout equipment can take up too much space.

Requirements:

- Each hook should be short.
- Each should sound conversational.
- Each should create curiosity.
- Use different angles such as problem, discovery, beginner experience, convenience and product demonstration.
- Avoid exaggerated advertising language.

The hooks should be suitable for Instagram Reels, Instagram Ads and YouTube Shorts.
